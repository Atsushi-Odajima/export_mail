# Samurai Dealer Research（英国中古車販売店の調査アプリ）

日本から英国への中古車販売の営業候補として、英国の中古車販売店を**発見・調査**し、分類・日本語概要・公開メールまたは問い合わせ方法・出典を確認するための日本語アプリです（第1段階：調査機能）。

- 外部AI・有料API・クレジットカード登録なしで動きます（候補発見の Firecrawl だけは任意。自分の APIキーを入れた場合のみ使用）。
- 営業メールの作成・送信、問い合わせフォームへの送信、予約送信は**実装していません**。将来の追加方法は [FUTURE_EMAIL_PLAN.md](FUTURE_EMAIL_PLAN.md) にまとめています。
- 確認済みの初期データ（実在の英国販売店）を同梱しています。内容と確認方法は [docs/INITIAL_DATA_REPORT.md](docs/INITIAL_DATA_REPORT.md)、検証結果は [docs/VERIFICATION.md](docs/VERIFICATION.md) を参照してください。

## iPhone 版（主な使い方）

**PC を使わず iPhone だけで使う場合は [mobile/README.md](mobile/README.md) を参照してください。** Cloudflare の無料プラン（Workers ＋ D1）に置き、Safari からホーム画面に追加して使う Web アプリです。調査の規則・データの形・販売店ID は下の Windows 版と共通です。

以下は Windows（PC）版の説明です。

## 1. 起動（Windows 配布版）

1. `SamuraiDealerResearch-windows.zip` を入手します（GitHub の Actions → `windows-build` の最新の成功した実行 → Artifacts。30 日で消えるため、必要なら Windows PC で `scripts\build_windows.bat` を実行して作り直せます）。
   ZIP を任意の場所（例：`ドキュメント`）に展開します。
2. 展開したフォルダーの `SamuraiDealerResearch.exe` をダブルクリックします。
   - 黒いウィンドウが開き、少しすると既定のブラウザーで日本語の画面（`http://127.0.0.1:8765/`）が開きます。
   - 初回だけ Windows の「PC を保護しました」が出る場合があります（署名のないアプリのため）。「詳細情報」→「実行」で起動します。
   - 待ち受けはこの PC 内（127.0.0.1）だけです。ほかの PC からは見えません。
3. 終了するときは、画面右上の **「アプリを終了」** を押します（黒いウィンドウを閉じても終了します）。終了後にサーバーは残りません。
4. もう一度 exe を起動すると、前回のデータが表示されます。すでに起動中なら、ブラウザーで既存の画面を開くだけです。

Python の導入は不要です。対象は Windows 10/11（64bit）です。

### データの保存場所

`%LOCALAPPDATA%\SamuraiDealerResearch`（例：`C:\Users\あなた\AppData\Local\SamuraiDealerResearch`）

| ファイル | 内容 |
|---|---|
| `dealers.sqlite3` | 正本のデータベース（販売店・連絡方法・根拠・履歴・候補・ジョブ） |
| `backups\` | バックアップ ZIP、更新前の自動バックアップ |
| `logs\app.log` | 動作記録（APIキー・パスワードは書きません） |
| `secrets.json` | Firecrawl の APIキー（設定した場合のみ。バックアップ・CSV には含めません） |

アプリ本体のフォルダーを新しい版に置き換えても、このデータは消えません。**各 PC に配布した場合、データは PC ごとに別々で、自動では同期しません。** 同じ一覧を複数人で使う場合は「6. 共有モード」を使ってください。

## 2. 画面の操作

| 画面 | できること |
|---|---|
| **販売店一覧** | 店名・地域・分類・概要・公開メール・問い合わせ方法・確認日・調査状態の一覧。店名／地域／分類／メールあり／フォームあり／要確認／調査状態で絞り込み。CSV 出力。選択した販売店の（再）調査 |
| **詳細** | 調査根拠（抜粋・出典を開く・観測日時）、連絡方法ごとの状態と出典、手動編集、メモ、人の確認、再調査、重複・支店の整理、取得ページの記録、変更履歴 |
| **候補発見** | 地域・分野・件数を指定して候補を集める。**自動検索**（OpenStreetMap・Firecrawl）と**手動補助**（検索ページをブラウザーで開くだけ）を分けて表示 |
| **候補一覧** | 発見した候補を確認し、販売店として登録・調査開始・除外 |
| **URL追加・CSV取込** | 公式サイトの URL を貼り付け、または CSV で取込み、そのまま調査開始 |
| **調査の進捗** | 進捗・停止・再開・失敗分の再実行・失敗理由 |
| **設定・バックアップ** | 取得の設定、Firecrawl APIキー、バックアップ・復元、初期データの読込 |

### 表示の意味（大事な点）

- **分類根拠**：「公式に専門店と明記」＝公式サイトに専門・販売の記載がある。「確認した在庫からの傾向」＝確認した在庫ページの範囲での傾向（全在庫は未確認で、専門店とは限らない）。「要手動確認」＝自動では判断できない。
- **公開メール確認済み**：販売店の公式サイトで公開表示を確認しただけです。**届くかどうか、営業メールを送ってよいかは確認していません。** 確認メールや SMTP 接続による宛先検査もしません。
- **公開メール未確認**：調べた範囲で見つからなかったという意味で、メールが存在しないとは限りません。
- **除外**：求人用・個人情報窓口・制作会社等のアドレスは販売店の窓口として採用しません（理由を表示）。別ドメインのアドレスは「要手動確認」です。
- **フォーム確認済み**／**問い合わせページあり・フォーム未確認**／**要手動確認**：検索欄・ログイン・ニュースレター登録は問い合わせフォームに数えません。外部サービスの埋め込み（HubSpot 等）で中身が見えない場合は「要手動確認」です。
- **人が確定**：人が入力した値。再調査しても上書きしません。空欄で保存すると自動取得値の表示に戻ります。

### 調査の流れ

1. 候補を集める（候補発見・URL 貼り付け・CSV）。URL の推測や架空企業の登録はしません。
2. 調査：トップ・会社紹介・問い合わせ・在庫ページなど（既定で 1 サイト最大 10 ページ）を取得し、店名・所在地（郵便番号）・中古車販売の記載・分類・メール・フォーム・電話を抽出します。
3. 人が詳細画面で根拠を見て、名称・公式サイト・分類・連絡方法を確認し「人が確認済みにする」を押します。

調査はバックグラウンドで進み、画面は操作できます。アプリを閉じても完了分は保存され、未完了分は「調査の進捗」から**再開**できます。

### 取得の制約（サイトに負荷をかけないため）

- robots.txt を確認し、不許可のページは取得しません。
- 同一サイトへの同時取得 1、取得間隔 2 秒以上、全体の同時調査 2、1 サイト最大 10 ページ（設定で変更可。間隔は 2 秒未満にできません）。
- 通信の制限時間 15 秒、1 ページ最大 2MB、再試行 1 回、取得キャッシュ 24 時間。
- アクセス制限・CAPTCHA・ボット確認ページ・HTTP 403 は**回避しません**。「取得失敗（理由）」として記録するので、ブラウザーで確認して手動で登録してください。
- http/https の公開 URL だけを扱います。localhost・内部 IP・クラウドの管理用アドレス・ローカルファイル等は、転送先や名前解決後のアドレスも含めて拒否します。
- 取得した HTML は実行せず、画面では文字として表示します。外部ページの文章をアプリへの命令として扱いません。

## 3. 追加調査（新しい販売店を探す）

### A. OpenStreetMap（無料・APIキー不要・自動）

候補発見 → 地域を選ぶ →「OpenStreetMap から候補を集める」。OpenStreetMap に `shop=car`（自動車販売店）として登録され、ウェブサイトが記載された店を集めます。

- 利用するサービス：Overpass API の公開インスタンス（OSM Wiki の一覧 https://wiki.openstreetmap.org/wiki/Overpass_API に掲載。英国・アイルランド向けの `overpass.atownsend.org.uk` を優先し、つながらない場合に `overpass-api.de`、`maps.mail.ru` の順で試します）。主インスタンスの利用方針は「1 日 1 万回未満・1GB 未満なら他の利用者の妨げにならない、定常利用はその 1/100 程度、並列実行しない」（2026-10-24 確認）。本アプリは 1 回の操作で 1 回だけ問い合わせます。混雑時は失敗することがあり、稼働保証はありません。
- データ：© OpenStreetMap contributors（ODbL 1.0）。登録内容は有志による入力で、網羅的ではありません。新車ディーラーも含まれるため、調査で中古車販売を確認します。
- この開発環境では `overpass.atownsend.org.uk` 経由で実際に候補を取得できることを確認しました（docs/VERIFICATION.md 参照）。`overpass-api.de` はこの環境の回線制限で接続できず未検証です。

### B. Firecrawl 検索（任意・APIキーが必要）

設定画面で APIキーを入れた場合だけ使えます（https://www.firecrawl.dev/ で登録）。

- 2026-10-24 に公式料金ページ（https://www.firecrawl.dev/pricing ）で確認した内容：Free プランは **毎月 1,000 クレジット・クレジットカード不要**、検索は **10 件あたり 2 クレジット**、同時 2 リクエスト。料金・条件は変わることがあるため、使う前に公式ページで確認してください。商用利用の制限は料金ページに記載がありませんでした（利用規約は各自で確認）。
- アプリ側の上限：月間使用上限（既定 200 クレジット）と 1 回あたりの最大件数（既定 20 件）。上限に達すると実行しません。残高不足（HTTP 402）でも止まり、**有料プランへ自動で切り替えません**。
- 使用量はデータベースに記録します。APIキーは `secrets.json` にだけ保存し、データベース・バックアップ・CSV・ログには入れません。
- APIキーを持っていないため、**この開発環境では実際の検索は未検証**です（応答の読み取りは試験で確認）。

### C. 手動補助（ブラウザーで開くだけ）

候補発見画面の Google・Bing・Google マップ・OpenStreetMap のリンクは、検索語を入れた検索ページを新しいタブで開くだけです。**アプリは検索結果を取得しません。** 見つけた販売店の公式サイト URL を「URL追加」に貼り付けてください。車両掲載サイト（AutoTrader 等）やアイルランドのサイトは登録できません。

### D. CSV 取込

見出しに `URL`（または `公式サイト` / `website`）列が必要です。任意で `店名` `地域` `メモ`。UTF-8 または Shift_JIS、2MB・2000 行まで。

## 4. CSV 出力

一覧画面の「この一覧をCSV出力」（絞り込み条件どおり）、「連絡方法CSV」「根拠CSV」。UTF-8（BOM 付き）で Excel でも文字化けしません。`=` `+` `-` `@` などで始まる値は先頭に `'` を付け、Excel で数式として実行されないようにしています。

CSV は入出力用です。正本はデータベースで、ID・根拠・履歴を含む完全な保存は次のバックアップで行います。

## 5. バックアップ・復元・更新

### バックアップ

設定・バックアップ画面の「今すぐバックアップ」で `backups\sdr-backup-日時-manual.zip` を作ります（画面からダウンロードも可）。中身はデータベース全体（販売店 ID・人の確定値・根拠・変更履歴・候補）と説明ファイルです。取得キャッシュ・ログイン情報・APIキーは含めません。

コマンドでも作れます：`SamuraiDealerResearch.exe backup`

### 復元

画面の「復元」で ZIP を選び、確認欄にチェックして実行します。**復元の直前に現在のデータを自動でバックアップ**します（`before-restore` の ZIP）。アプリを終了した状態でコマンドから復元することもできます：`SamuraiDealerResearch.exe restore バックアップ.zip`

### アプリの更新（データを保持したまま）

1. 画面でバックアップを作る（念のため）。
2. アプリを終了し、アプリのフォルダーを新しい版に置き換える（データフォルダーには触れない）。
3. 新しい版を起動すると、データベースの版（`schema_meta.schema_version`）を確認し、必要な更新（列・テーブルの追加）を自動で行います。**更新の直前に `backups\pre-migration-v版-日時.sqlite3` を自動作成**します。

### 更新に失敗したとき

- 更新処理は 1 段階ずつトランザクションで行い、失敗したら更新前の状態に戻して起動を止めます（データは更新前のまま）。
- 元に戻すには：旧版のアプリに戻すか、アプリを終了した状態で `backups\pre-migration-...sqlite3` を `dealers.sqlite3` という名前でデータフォルダーに上書きコピーします（`dealers.sqlite3-wal` `-shm` があれば削除）。
- 新しい版で作ったデータベースを古い版で開こうとすると、壊さないよう起動を止めます。

## 6. 共有モード（自分の PC をサーバーにして友人と使う）

データはサーバー役の PC にだけ保存し、利用者はブラウザーから同じ一覧を使います。SQLite ファイルをネットワーク共有して各 PC から直接開く使い方はしないでください。小規模（2 人程度）を想定しています。

### 準備（サーバー PC）

```bat
SamuraiDealerResearch.exe create-user alice
SamuraiDealerResearch.exe create-user bob
```

パスワード（10 文字以上）は対話で入力します。既定の共通パスワードはありません。パスワードは scrypt でハッシュ化して保存し、ログイン後は HttpOnly・Secure・SameSite のセッション Cookie（12 時間）で管理します。更新操作はすべて CSRF トークンで保護し、5 回続けて失敗すると 15 分間ログインを受け付けません。

```bat
SamuraiDealerResearch.exe shared --allowed-host あなたの公開ホスト名
```

既定では `127.0.0.1:8780` だけで待ち受けます（ログイン必須。未ログインでは一覧・CSV・調査実行の API に到達できません）。127.0.0.1 以外で待ち受ける場合は HTTPS 証明書（`--certfile` `--keyfile`）が必要で、指定がなければ起動しません。**ルーターのポート開放は手順にしていません。**

### 接続方法（HTTPS の経路）

| 方法 | 位置づけ | 無料か | 注意 |
|---|---|---|---|
| Cloudflare Quick Tunnel（`cloudflared tunnel --url http://127.0.0.1:8780`） | **一時的な試用用** | アカウント不要 | 公式に「試験・開発用」、稼働保証なし、起動のたびに URL が変わる（2026-10-24 確認：https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/trycloudflare/ ）。表示された `xxxx.trycloudflare.com` を `--allowed-host` に指定 |
| Cloudflare Tunnel（名前付き） | 継続運用向け | Cloudflare のアカウントは無料で作れるが、**インターネットに公開するには Cloudflare に登録した自分のドメインが必要**（ドメイン代は有料）（公式手順の前提条件、2026-10-24 確認） | Cloudflare Access（Zero Trust）で利用者のメール認証を前段に置くとより安全。Zero Trust の無料枠の人数上限などは導入時に公式ページで確認 |
| Tailscale | 継続運用の代替 | Personal プランは無料だが、公式に**非商用のみ**（2026-10-24 確認：https://tailscale.com/pricing ）。業務利用は有料プラン | 業務で「完全無料」とは扱えません |

外部公開・サービス契約はこのアプリからは行いません。利用者自身が判断して設定してください。

### 注意

- サーバー PC が停止・スリープ・回線切断中は利用できません。
- 共有モードでは画面から終了できません。サーバー PC のウィンドウで `Ctrl+C` を押します。
- 共有モードで調査を実行すると、取得はサーバー PC の回線から行われます。

## 7. 開発者向け

```sh
uv venv -p 3.12 .venv            # または python -m venv .venv
. .venv/bin/activate             # Windows: .venv\Scripts\activate
pip install -r requirements.txt -r requirements-dev.txt
python -m pytest -q tests        # 試験（架空データのみ使用）
python run_app.py local          # 開発用起動（--data-dir で保存先を変更可）
```

- Windows 配布版の作成：Windows PC で `scripts\build_windows.bat`（Python 3.12 64bit が必要）。GitHub に push すると `.github/workflows/windows-build.yml` が Windows ランナーで試験・ビルド・起動確認を行い、ZIP を成果物として保存します。
- 構成（処理ごとにファイルを分けています）

| ファイル | 役割 |
|---|---|
| `sdr/discovery.py` | 候補発見（OSM・Firecrawl・手動補助のリンク作成） |
| `sdr/fetcher.py` `sdr/netsafe.py` | 安全な取得（robots.txt・間隔・サイズ・転送先確認・内部アドレス拒否） |
| `sdr/extract.py` | HTML からの抽出（メール・フォーム・郵便番号・構造化データ） |
| `sdr/classify.py` | ルールによる分類・メール判定・日本語概要（外部 AI なし） |
| `sdr/research.py` | 1 社の調査の流れ |
| `sdr/repo.py` | データ操作の集約（販売店・連絡方法・根拠・履歴・候補・ジョブ） |
| `sdr/db.py` | 接続・データベースの版管理（移行） |
| `sdr/jobs.py` | バックグラウンド処理（停止・再開・中断復旧） |
| `sdr/backup.py` `sdr/csv_io.py` `sdr/seed.py` | バックアップ・CSV・初期データ |
| `sdr/auth.py` `sdr/web.py` `sdr/templates/` | 認証・画面 |
| `sdr/main.py` | 起動・コマンド |
| `scripts/research_urls.py` | 開発用：URL 一覧を画面なしで一括調査 |

- 依存ライブラリと版は `requirements.txt` に固定しています。ライセンスは [LICENSES.md](LICENSES.md)。
- 試験用の架空データは `tests/fixtures/` だけに置き、実データ（`sdr/seed/`）と分けています。
